# Demo bundle

Trained checkpoints (`checkpoints/*/best.pt`), the results database (`data/mti.sqlite3`: experiments, evaluations,
analyses), per-run logs/history, and the official AI4Mars expert test split (322 images + min1/min2/min3 labels)
with a dataset index trimmed to those records. `deploy/render.Dockerfile` copies this folder into the image, so a
hosted instance starts with the trained models and real results. Generated by `scripts/deploy_space.py --stage`.

AI4Mars images and labels: Zenodo doi:10.5281/zenodo.15995036, CC-BY-4.0 (R. Swan, M. Ono, D. Atha).
Training images are not included; training is disabled in public mode.
